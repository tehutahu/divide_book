# divide_book

ローカル動画から、一定時間静止しているページ・スライドをPNGに抽出する小さなCLIです。
画面表示や外部APIは不要です。出力は元の解像度を保ちます。

## 準備

Python 3.10以降を使用します。仮想環境内に依存をインストールしてください。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py "C:\videos\slides.mp4" -o "out\slides-run1"
```

macOS/Linuxでは `.venv/bin/python` を使用します。相対・絶対パスと空白を含むパスに対応します。
`-o`省略時は、作業ディレクトリの `out/<動画ファイル名>` に保存します。

```powershell
.venv\Scripts\python main.py "slides.mp4" -o "out\slides-run2" --pdf "slides-run2.pdf"
.venv\Scripts\python main.py --help
.venv\Scripts\python -m unittest discover -s tests -v
```

PNGは `0001.png`, `0002.png`, … の順です。PDFは指定した場合だけ作成します。
既存の出力ディレクトリ・PDFは上書きしません。再実行時は新しい名前を指定してください。
入力を変更・削除しません。失敗時は非ゼロの終了コードとエラーを返します。
途中で書き込みに失敗した場合、生成済みファイルは残ります。PDF失敗時もPNGは残ります。

## 検出と調整

既定では0.25秒以上ほぼ変わらないフレームを1ページとして保存します。
安定区間の開始画像と比較するので、ゆっくりした変化も累積して検出します。
先頭・末尾も安定時間を満たすと保存します。単一フレームの動画は1枚保存します。
短すぎる区間は保存しません。隣接する同じページは省き、別ページを挟んだ再訪は残します。

| オプション | 既定値 | 用途 |
| --- | --- | --- |
| `--stable-seconds` | `0.25` | 短いページには小さく、画面送りが残る場合は大きくする |
| `--pixel-threshold` | `20` | 0～255の色差。小さくすると微細な変更に敏感になる |
| `--changed-fraction` | `0.001` | 色差を超える画素の許容割合。0以上1未満 |

比較画像の長辺を最大640画素に縮小します。微細な文字差、カーソル、動画圧縮ノイズは
設定次第で見逃したり別ページと判定したりします。静止した中間アニメーションも、指定時間を
超えるとページに数えます。OCRやページ内容の意味判定は行いません。
読み取りが終了した時点を動画の終端とみなすため、途中のデコード失敗と正常な終端を
すべてのコーデックで区別できるわけではありません。フレームレート情報が必要です。
PDF変換は全ページをメモリに読み込むため、大きな動画ではPNGのみの出力を推奨します。

テストは合成FFV1動画のみを使用し、先頭末尾、フェード、ノイズ、重複、ページ再訪、
小さな変更、短い区間、パス、上書き拒否、エラー、PDFを検証します。
